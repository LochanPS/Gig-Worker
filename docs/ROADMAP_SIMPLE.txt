FLOW — one payment, end to end
  Company clicks New Payout
    -> POST /payments
    -> Compliance engine runs 10 rules -> verdict (APPROVE / FLAG / REJECT)
    -> Agent writes plain-English reasoning
    -> decision hash anchored on-chain (AuditAnchor)
    -> FX quote + 10-min rate lock shown (fee vs PayPal)
    -> Company confirms
    -> EscrowVault.fund()   [state: FUNDED]
    -> EscrowVault.release() [SETTLING -> COMPLETED]
    -> payee gets amount-fee, treasury gets fee
    -> WebSocket ticks all 3 dashboards live
    -> Freelancer sees money + "You kept 99.25%"

[2026-09-04] MOCK WS CRASH (P3 -> P2, action needed in backend/mock/server.ts)
  backend/mock/server.ts uses `conn.socket.send(...)` / `conn.socket.on(...)`.
  @fastify/websocket v10 (installed) passes the WebSocket itself as the first
  handler argument, so `conn.socket` is undefined. On the first metrics tick the
  handler throws inside setInterval, which is an UNCAUGHT exception and kills the
  whole mock process, taking every REST endpoint down with it.
  Fix: use `conn.send(...)` and `conn.on('close', ...)` (the arg IS the socket),
  or destructure `(socket) =>`. P3 runs a locally patched bundle for the demo;
  the repo source still needs this one-line fix.
